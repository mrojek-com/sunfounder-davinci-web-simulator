Raspberry Pi 2 Model B (40-Pin GPIO Header)

The Raspberry Pi 2 Model B features a 40-pin GPIO connector matching all modern 40-pin Raspberry Pi boards. Pins labeled in green are 3.3V logic GPIOs. Never connect 5V directly to any GPIO pin!

Left Column (Odd Pins) Pin Pin Right Column (Even Pins)

⚠️ Pre-Wiring Safety Invariants for Raspberry Pi 2B

  • 3.3V Logic Tolerance: Raspberry Pi GPIO pins are strictly 3.3V tolerant. An input voltage higher than 3.3V will permanently burn the SoC GPIO bank. Always use a voltage divider (e.g., for 5V ultrasonic echo pins) or an ADC0834 chip.
  • Maximum Pin Current: Maximum current draw from a single GPIO pin is 16mA (recommended ≤ 3mA). Total combined current from all 3.3V pins must never exceed 50mA.
  • T-Cobbler Ribbon Cable Orientation: The red stripe on the 40-pin ribbon cable MUST correspond to Pin 1 (3.3V Power) on both the Raspberry Pi and the T-Cobbler. Reversing the cable will swap power and ground rails.
  • Power Supply: Always power your Raspberry Pi 2B with a stable 5V / 2.0A or 2.5A Micro-USB adapter.
